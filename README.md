# 💫 About Me:
I am a Computer Science undergraduate specializing in Machine Learning with a strong interest in building and evaluating intelligent systems. Currently pursuing my B.Tech in Computer Science at Vidya Jyothi Institute of Technology in Hyderabad, I enjoy working on practical AI and data-driven projects that solve real-world problems. <br><br>I have hands-on experience developing machine learning applications such as a fake news detection system for Indian news articles, a content-based movie recommendation system using the TMDB dataset, and a linear regression model built from scratch in Python. Through these projects, I have gained experience in data preprocessing, model building, evaluation, and visualization using tools like Python, scikit-learn, Pandas, NumPy, Matplotlib, and Streamlit. <br><br>In addition to technical skills in Python, SQL, Java, and C, I am particularly interested in model evaluation, output analysis, and improving the reliability of AI systems. I focus on maintaining attention to detail, analytical thinking, and clear communication when analyzing machine learning results. <br><br>My goal is to grow as a Machine Learning Engineer and contribute to building reliable AI systems, especially in areas involving image, video, and data-driven model evaluation in real-world applications.
